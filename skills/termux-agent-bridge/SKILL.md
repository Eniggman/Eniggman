# 📱 Termux Agent Bridge (MCP)

Экспертный навык для ИИ-агентов (OpenAI Codex, Claude Code, Google Antigravity, Gemini Spark) по удалённому управлению средой Android Termux (Linux) прямо с вашего ПК.

Репозиторий проекта: **[Enigman-Termux-lab/termux-agent-bridge](https://github.com/Enigman-Termux-lab/termux-agent-bridge)**

---

## ⚡ Возможности
- Прямое выполнение команд в Termux (ARM64 Linux) через глобальный защищенный туннель
- 4 профиля безопасности (`monitor`, `workspace`, `interactive`, `godmode`)
- Интерактивное подтверждение потенциально опасных команд в Android Push (`termux-notification`)
- Мониторинг батареи, температуры устройства и системных датчиков
- Подключение по стандартному открытому протоколу Streamable HTTP / SSE без сложных OAuth2 и сторонних плагинов
