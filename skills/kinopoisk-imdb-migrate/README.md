## 🛡 Шаг 0. Настрой VPN (обязательно!)

Без VPN Кинопоиск может отдавать ошибку `403` или капчу, а IMDb может резать запросы с «подозрительных» IP.

### Что делать:

1. **Установи VPN-клиент с обфускацией трафика.**
   Подойдут: Shadowsocks, V2Ray (VLESS), Xray, AmneziaWG, OpenVPN + Stealth-патч.

2. **Настрой подключение на порт `443`.**
   Это стандартный HTTPS-порт. Провайдер видит твой трафик как обычный веб — не блокирует.

3. **Проверь:** открой [свои оценки на Кинопоиске](https://www.kinopoisk.ru/mykp/movies/) — страница должна открыться без капчи.

> ⚠️ **Почему именно порт 443?** Обычные VPN-порты (1194, 51820) легко определяются провайдером через DPI (Deep Packet Inspection) и блокируются. Порт 443 маскирует VPN под обычный HTTPS-трафик — его не отличить от обычного серфинга.

## 📥 Шаг 1. Собери данные с Кинопоиска

Мы **не используем** API Кинопоиска (оно закрыто). Вместо этого берём данные прямо из страницы через консоль браузера.

### 1.1. Подготовь страницу

1. Открой **[свои оценки](https://www.kinopoisk.ru/mykp/movies/)** на Кинопоиске.
2. Внизу страницы выбери **«Показывать по 200»**.
3. **Прокрути страницу до самого низа**, чтобы все фильмы прогрузились.

### 1.2. Запусти парсер

1. Нажми **F12** → вкладка **Console**.
2. Скопируй и вставь **весь код** из файла `extract_movies.js`.
3. Нажми **Enter**.

### 1.3. Что ты получишь

В консоли появится список в формате:
```
Название фильма | Оценка: 8 | Дата: 29.09.2025, 14:40
```

4. **Скопируй весь вывод** в созданный текстовый файл `data/watched.txt`.
5. Если фильмов больше 200 — перейди на следующую страницу и повтори.

### 1.4. Список «Буду смотреть» (Watchlist)

Повтори то же самое на странице **«Буду смотреть»**:
1. Открой раздел «Буду смотреть» в своём профиле.
2. Вставь `extract_movies.js` в консоль.
3. Сохрани результат в файл `data/watch_later.txt`.

> 💡 **Совет:** через VPN загрузка страниц может идти медленно — просто подождите

## 🧹 Шаг 2. Создай CSV-базу из собранных данных

Теперь нужно превратить текстовый вывод из консоли в структурированную базу.

### 2.1. Создай файл `data/кинопоиск_база.csv`

Формат: **CSV с разделителем `;`** (точка с запятой — потому что обычная запятая ломает названия вроде «Старик, море и кот»).

**Колонки:**
```
Название (RUS);Название (ENG);Оценка;Дата просмотра
```
### 2.2. Добавь английские названия

Если у фильма нет английского названия — погугли или оставь пустым. Скрипт `rebuild_watched.py` подхватит оба варианта.

### 2.3. Проверь данные

Открой CSV в Excel/LibreOffice и убедись:
- Нет дубликатов
- У каждого фильма есть оценка
- Даты в формате `ДД.ММ.ГГГГ, ЧЧ:ММ`

## 🌐 Шаг 4. Получи IMDb ID через Letterboxd

IMDb не понимает русские названия. Для каждого фильма нужен идентификатор формата `tt1234567`. Самый надёжный способ — использовать Letterboxd как «мост».

### 4.1. Конвертируй базу кинопоиск_база.csv в формат Letterboxd

```bash
python Scripts/convert_to_letterboxd.py
```

Скрипт создаст файл `data/letterboxd_import.csv` с колонками `Title, Year, Rating10, WatchedDate`.

### 4.2. Импортируй в Letterboxd

1. Зайди на **[letterboxd.com](https://letterboxd.com)** → **Settings** → **Import & Export**.
2. Загрузи файл `letterboxd_import.csv`.
3. Letterboxd сам сопоставит названия с IMDb ID.
4. Подожди несколько минут — импорт может быть медленным.

### 4.3. Экспортируй из Letterboxd

1. На той же странице **Import & Export** нажми **Export your data**.
2. Скачай ZIP-архив и распакуй в папку `letterboxd_export/`.
3. Тебя интересует файл `ratings.csv` — в нём будут ссылки на Letterboxd-страницы.

### 4.4. Извлеки IMDb ID из Letterboxd

```bash
python Scripts/extract_from_letterboxd.py
```

Скрипт:
- Парсит каждую Letterboxd-страницу из `letterboxd_export/ratings.csv`
- Находит ссылку на IMDb
- Сохраняет результат в `data/imdb_import_clean.json`

> ⚠️ Это занимает 2–5 минут. Скрипт использует 10 потоков, но делает паузы, чтобы Letterboxd не заблокировал.

## 🔍 Шаг 5. Дозаполни пропущенные ID

Letterboxd может не найти все фильмы. Заполни пробелы сам

### 5.1. Автозаполнение через IMDb API

```bash
python Scripts/prepare_watchlist.py
```

Скрипт стучится в скрытый эндпоинт IMDb:
```
https://v3.sg.media-imdb.com/suggestion/x/{название}.json
```
Этот API возвращает варианты по названию. Найденные ID автоматически вшиваются в JSON.

> 💡 **Ручные маппинги:** Если у тебя есть фильмы, которые невозможно найти по названию (кириллица, редкие), добавь их в словарь `manual_fixes` в начале скрипта:
> ```python
> manual_fixes = {
>     "Конец грёбаного мира": "tt6257970",
>     "Доказательство смерти": "tt0452637",
> }
> ```

### 5.2. Проверь правильность ID

```bash
python Scripts/check_ids.py
```

Скрипт берёт ~13% случайных фильмов и проверяет, что `tt`-ID ведёт на правильный фильм.




## 📦 Шаг 6. Подготовь данные для импорта

### 6.1. Выстрой правильный порядок

```bash
python Scripts/fix_order.py
```

Скрипт читает `watched.md` и выстраивает JSON **в обратном порядке** — самый старый фильм первым. Это нужно, потому что IMDb показывает последний добавленный фильм первым. Если грузить от старого к новому — хронология на IMDb совпадёт с `watched.md`.

### 6.2. Разбей на порции

```bash
python Scripts/make_chunks.py
```

Создаёт файлы в `data/import_chunks/`:
```
пример:
part_1_5_items.json      ← первые 5 (для теста)
part_2_10_items.json     ← следующие 10
part_3_20_items.json     ← следующие 20
part_4_40_items.json     ← следующие 40
part_5_102_items.json    ← остальные
```

> 💡 **Зачем порции?** Если импорт упадёт на 80-м фильме, не придётся перегружать все заново. Запусти только оставшиеся чанки.


## 🚀 Шаг 7. Импортируй оценки (Ratings) на IMDb

Для импорта **оценок** используем готовый Tampermonkey-скрипт с GreasyFork. Он берёт JSON-файл с оценками и автоматически ставит их на IMDb через внутренний API.

### 7.1. Установи Tampermonkey

1. Установи расширение **[Tampermonkey](https://www.tampermonkey.net/)** в свой браузер (Chrome / Edge / Opera).
2. В настройках расширений браузера **включи режим разработчика** (Developer Mode) — без него скрипты не устанавливаются.

### 7.2. Установи скрипт-импортер

Перейди по ссылке и нажми **Install**:
👉 **[IMDb Ratings Importer (JSON)](https://greasyfork.org/en/scripts/573527-imdb-ratings-importer-json)**

> Этот скрипт добавляет кнопку **«Import Ratings (JSON)»** на страницу твоих оценок на IMDb.

### 7.3. Подготовь JSON-файл

Формат файла `data/imdb_import_clean.json`:
```json
[
  {"imdb": "tt0816692", "rating": 10, "name": "Interstellar"},
  {"imdb": "tt1375666", "rating": 9, "name": "Inception"},
  ...
]
```

Каждый объект содержит:
- `imdb` — IMDb ID фильма (формат `tt1234567`)
- `rating` — твоя оценка от 1 до 10
- `name` — название (для отображения в логе)

> ⚠️ **Порядок имеет значение!** IMDb показывает последний оценённый фильм первым. Чтобы хронология совпала с `watched.md`, список должен быть **перевёрнут** (самый старый просмотр — первым). Скрипт `fix_order.py` делает это автоматически.

### 7.4. Запусти импорт

1. Зайди на **[свою страницу оценок IMDb](https://www.imdb.com/ratings/)**.
2. Убедись, что ты **залогинен**.
3. Вверху страницы появится кнопка **«Import Ratings (JSON)»** — нажми её.
4. Выбери файл `data/imdb_import_clean.json` (или чанк из `data/import_chunks/`).
5. Скрипт начнёт автоматически ставить оценки.

### 7.5. Следи за процессом

На странице появится прогресс-бар и лог:
```
✅ Interstellar — rated 10
✅ Inception — rated 9
❌ Some Movie — FORBIDDEN: This title is not yet open for voting.
```

## 🚀 Шаг 8. Импортируй Watchlist (Буду смотреть) на IMDb

Для списка **«Буду смотреть»** (Watchlist) используем другой метод — скрипт `imdb_watchlist_importer.js`, который работает через iframe + реальные клики.

### Почему не тот же скрипт?

Скрипт с GreasyFork умеет только ставить **оценки**. Добавление в Watchlist — это другая операция, для которой IMDb использует другой API. Все попытки дёрнуть его напрямую блокируются:

| Метод | Результат |
|-------|-----------|
| GraphQL API напрямую | ❌ Нужен CSRF-токен `at-main` из `HttpOnly` куки — JS не может его прочитать |
| POST на `/watchlist/{id}/add` | ❌ Эндпоинт мёртв, возвращает `404` |
| **Iframe + настоящий клик** | ✅ Браузер сам прикрепляет все куки и токены |

### 8.1. Подготовь скрипт

Открой файл `Scripts/imdb_watchlist_importer.js`. Найди массив `HARDCODED_MOVIES` в начале файла и **замени его на свой JSON** из `data/imdb_watchlist_import.json` (или из чанка).

Формат массива:
```json
[
  {"name": "Cloud Atlas", "imdb": "tt1371111"},
  {"name": "V for Vendetta", "imdb": "tt0434409"},
  ...
]
```

> ⚠️ **Важно:** Оставь только `name` и `imdb`. Поля `rating`, `original_name`, `year` — убери.

### 8.2. Запусти импорт

1. Открой свой **[IMDb Watchlist](https://www.imdb.com/watchlist/)**.
2. Убедись, что ты **залогинен** (видишь свой никнейм в углу).
3. Нажми **F12** → вкладка **Console**.
4. Вставь **весь код** из `Scripts/imdb_watchlist_importer.js`.
5. Нажми **Enter**.
6. На странице появится жёлто-чёрная панель **IMDb Importer**.
7. Нажми кнопку **START DUAL-MODE IMPORT**.

### 8.3. Что происходит

- Скрипт пробует добавить фильм через **GraphQL** (быстрый метод).
- Если GraphQL не сработал — использует **классический POST** (fallback).
- Между запросами пауза **1.2 секунды**, чтобы не триггерить WAF (файрвол IMDb).

### 8.4. Следи за процессом

В логе на странице ты увидишь:
```
[12:34:56] [GQL SUCCESS] Cloud Atlas          ← добавлено ✅
[12:34:58] [CLASSIC SUCCESS] V for Vendetta    ← добавлено через fallback ✅
[12:35:00] [FATAL FAIL] Some Movie: Status 404 ← ошибка ❌
```

### 8.5. Правила во время импорта

| Правило | Почему |
|---------|--------|
| ❌ Не закрывай вкладку | Браузер «замораживает» неактивные вкладки |
| ❌ Не переключайся на другие вкладки | То же самое |
| ✅ Красные ошибки `BLOCKED_BY_ADBLOCKER` — это нормально | Блокировщик рекламы режет трекеры IMDb, на работу скрипта не влияет |
| ✅ Жди надпись **«🎯 MISSION ACCOMPLISHED!»** | Это финиш |

### 8.6. Если что-то пошло не так

- **Скрипт остановился посередине** → Открой Watchlist, посмотри сколько фильмов добавилось. Загрузи следующий чанк с того места, где остановился.
- **Все фильмы дают FATAL FAIL** → Скорее всего, ты не залогинен. Обнови страницу и проверь.
- **IMDb заблокировал запросы** → Подожди 10 минут и повтори с меньшим чанком.
